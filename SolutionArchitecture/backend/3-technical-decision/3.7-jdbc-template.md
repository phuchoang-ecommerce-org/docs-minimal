# JdbcTemplate

Status: proposed implementation decision for [roadmap section 3](inkdrop://note/uUXxpSnh), revision 83, read through MCP on 2026-11-07. Java examples show implementation slices, not a compiled backend. 

JdbcTemplate implements persistence ports; NamedParameterJdbcTemplate is appropriate for named parameters and collections. Use prepared parameters, explicit schema-qualified SQL and RowMapper projections. Spring JDBC translates persistence failures; application code maps known conflicts to stable HTTP errors. See [JDBC core](https://docs.spring.io/spring-framework/reference/data-access/jdbc/core.html).

```java
final class JdbcStockAdapter {
  private final org.springframework.jdbc.core.JdbcTemplate jdbc;
  JdbcStockAdapter(org.springframework.jdbc.core.JdbcTemplate jdbc) { this.jdbc = jdbc; }
  void decrease(java.util.UUID variantId, int quantity) {
    if (quantity <= 0) throw new IllegalArgumentException("quantity");
    int changed = jdbc.update("""
      UPDATE marketplace.stock
         SET on_hand = on_hand - ?, version = version + 1
       WHERE variant_id = ? AND on_hand >= ?
      """, quantity, variantId, quantity);
    if (changed != 1) throw new StockConflict();
  }
  static final class StockConflict extends RuntimeException {}
}
```

UC-04 calls this adapter in stable variant order within one application transaction. A late conflict rolls back all earlier decrements, voucher usage, snapshots and audit. Never catch and suppress the exception inside the transaction. JDBC adapters share the same DataSource/transaction manager; no `REQUIRES_NEW` for mandatory collaborators.

```java
record StockView(java.util.UUID variantId, int onHand, long version) {}
// In a query adapter; owner identity must be trusted, not supplied as an arbitrary filter.
StockView readOwned(org.springframework.jdbc.core.JdbcTemplate jdbc,
                    java.util.UUID variantId, java.util.UUID sellerId) {
  return jdbc.queryForObject("""
    SELECT s.variant_id, s.on_hand, s.version
    FROM marketplace.stock s JOIN marketplace.variant v ON v.id=s.variant_id
    JOIN marketplace.product p ON p.id=v.product_id
    WHERE s.variant_id=? AND p.seller_id=?
    """, (rs, row) -> new StockView(rs.getObject(1, java.util.UUID.class),
                                    rs.getInt(2), rs.getLong(3)), variantId, sellerId);
}
```

Translate empty results to non-owned/missing 404. Use `batchUpdate` for order-line inserts only after factory validation; verify update counts. Do not concatenate client sort columns into SQL; choose among fixed allowlisted orderings. Integration tests use PostgreSQL, never H2 as a locking substitute.

RowMapper performs ResultSet extraction; [MapStruct](./3.14-mapstruct.md) can convert an adapter-local row record to an immutable query projection. Root rehydration and optimistic update parameters are explicit code. Do not use a generated mapper as a repository or constructor bypass.

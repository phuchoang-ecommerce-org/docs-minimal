# JWT Access Token and RBAC

Use local password authentication and signed short-lived access JWTs, with no external identity provider or refresh workflow. Next.js stores the token in its secure HttpOnly cookie and forwards a Bearer header server-side; the API does not authenticate from that cookie. Preserve [security requirements](../../system/security.md) and [runtime profiles](../../system/runtime-profiles.md). Trace: UC-03 and every protected use case.

```java
@Bean
org.springframework.security.oauth2.jwt.JwtDecoder decoder(java.security.interfaces.RSAPublicKey key) {
  var decoder = org.springframework.security.oauth2.jwt.NimbusJwtDecoder.withPublicKey(key)
    .signatureAlgorithm(org.springframework.security.oauth2.jose.jws.SignatureAlgorithm.RS256).build();
  var issuer = org.springframework.security.oauth2.jwt.JwtValidators.createDefaultWithIssuer("marketplace");
  org.springframework.security.oauth2.core.OAuth2TokenValidator<org.springframework.security.oauth2.jwt.Jwt> audience =
    jwt -> jwt.getAudience().contains("marketplace-api")
      ? org.springframework.security.oauth2.core.OAuth2TokenValidatorResult.success()
      : org.springframework.security.oauth2.core.OAuth2TokenValidatorResult.failure(
          new org.springframework.security.oauth2.core.OAuth2Error("invalid_token"));
  decoder.setJwtValidator(new org.springframework.security.oauth2.core.DelegatingOAuth2TokenValidator<>(issuer, audience));
  return decoder;
}

@Bean
org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter jwtConverter() {
  var roles = new org.springframework.security.oauth2.server.resource.authentication.JwtGrantedAuthoritiesConverter();
  roles.setAuthoritiesClaimName("roles");
  roles.setAuthorityPrefix("ROLE_");
  var converter = new org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter();
  converter.setJwtGrantedAuthoritiesConverter(roles);
  return converter;
}
```

Use Spring Security's [resource-server JWT validation and authority conversion](https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html). The local issuer signs claims after password authentication, never using a role supplied in the request.

```java
// JwtEncoder is a NimbusJwtEncoder wired with an RSA private JWK from a secret file.
String issueToken(org.springframework.security.oauth2.jwt.JwtEncoder encoder,
                  java.util.UUID authenticatedAccountId, String persistedRole,
                  java.time.Clock clock) {
  if (!java.util.Set.of("MEMBER", "SELLER", "ADMIN").contains(persistedRole))
    throw new IllegalArgumentException("role");
  var now = clock.instant();
  var claims = org.springframework.security.oauth2.jwt.JwtClaimsSet.builder()
      .issuer("marketplace").subject(authenticatedAccountId.toString())
      .audience(java.util.List.of("marketplace-api")).issuedAt(now)
      .expiresAt(now.plusSeconds(900)).claim("roles", java.util.List.of(persistedRole)).build();
  var header = org.springframework.security.oauth2.jwt.JwsHeader
      .with(org.springframework.security.oauth2.jose.jws.SignatureAlgorithm.RS256).build();
  return encoder.encode(org.springframework.security.oauth2.jwt.JwtEncoderParameters.from(header, claims))
      .getTokenValue();
}
```

Enable method security and stateless Bearer authentication in the API. Route rules: allow POST /auth/login and POST /accounts, public GET discovery/reviews/image bytes and Guest cart endpoints; require MEMBER for checkout/private Member routes, SELLER for Seller routes, ADMIN for Admin routes; deny unspecified routes. Guest cart writes still require their opaque cart-session proof and origin/CSRF controls because they use a cookie. Disabling CSRF globally without that exception would be wrong. Next.js cookie-authenticated mutations independently enforce origin/CSRF protection.

```java
// Inside a use-case service after role checks, before reading private data:
var accountId = actor.authenticatedAccountId();
var sellerId = sellerDirectory.requireSellerIdForAccount(accountId);
var order = orders.lockById(orders.parentId(command.sellerOrderId()));
order.requirePortionOwner(command.sellerOrderId(), sellerId); // foreign -> 404
order.recordCod(command.sellerOrderId(), sellerId, clock.instant());
```

JWT subject is Account ID; SellerShop ID is resolved server-side and must not be assumed equal. Verify current account availability and Seller activation at relevant commands; a signed role alone cannot bypass suspension. Invalid/expired/wrong-signature/issuer/audience tokens return 401; wrong role 403; cross-owner ID 404. Use PasswordEncoder with a supported one-way hash, generic login errors, and no secret logging. Keep keys outside source control; rotate with an overlap limited to access-token validity. A 900-second lifetime is a proposed baseline, not a newly accepted product rule.

Acceptance: tampered token, forbidden role, foreign portion, suspended Seller checkout and production dev-login absence are covered by Security/MVC integration tests. Login/logout only creates/clears the frontend cookie; no token blacklist or long-lived refresh token is introduced.

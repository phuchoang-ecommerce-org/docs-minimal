# jMolecules

Status: proposed implementation decision for [roadmap section 3](inkdrop://note/uUXxpSnh), revision 83, read through MCP on 2026-11-07. Java examples show implementation slices, not a compiled backend. 

Use jMolecules annotations to make roots, identifiers and value objects visible to architecture verification. They do not implement authorization, validation, transactions or persistence. Select annotation style for this project; avoid mixing type-based and annotation-based conventions without a reason. [Official library documentation](https://github.com/xmolecules/jmolecules) describes both forms.

```java
import org.jmolecules.ddd.annotation.AggregateRoot;
import org.jmolecules.ddd.annotation.Identity;
import org.jmolecules.ddd.annotation.ValueObject;
import java.math.BigDecimal;
import java.util.UUID;

@ValueObject
public record OrderId(UUID value) {
  public OrderId { java.util.Objects.requireNonNull(value); }
}

@ValueObject
public record MoneyUsd(BigDecimal amount) {
  public MoneyUsd {
    amount = amount.setScale(2, java.math.RoundingMode.UNNECESSARY);
    if (amount.signum() < 0 || amount.precision() > 12)
      throw new IllegalArgumentException("Invalid USD amount");
  }
}

@AggregateRoot
public final class CustomerOrder {
  @Identity private final OrderId id;
  public CustomerOrder(OrderId id) { this.id = java.util.Objects.requireNonNull(id); }
  // Production creation goes through OrderFactory with nonempty portions.
  // cancel/recordCod enforce BR-08/09; annotations do not implement those guards.
}
```

The final class fragment demonstrates identity annotation only, not a complete order constructor contract. Production code must include the factory and invariants from section 1.2. Use `jmolecules-ddd` plus test-scoped `jmolecules-archunit`; Modulith verification can invoke available jMolecules rules. Do not add JPA bytecode integration: JdbcTemplate adapters explicitly map rows to domain values. Verify architecture failures with a fixture that illegally accesses another module's internal root.

jMolecules annotations do not relax the [MapStruct](./3.14-mapstruct.md) factory boundary or [Lombok](./3.15-lombok.md) handwritten-constructor rule. Root identity/equality and invariant-bearing construction remain explicit domain code.

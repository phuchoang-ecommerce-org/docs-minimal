# Clean Architecture

Status: proposed implementation decision for [roadmap section 3](inkdrop://note/uUXxpSnh), revision 83, read through MCP on 2026-11-07. Java examples show implementation slices, not a compiled backend. 

Use this target tree for the backend implementation repository. It is not a request to create executable application code in this documentation repository. The domain stays framework-free except optional jMolecules semantics; JdbcTemplate and Spring MVC stay in adapters.

```text
backend/
  settings.gradle.kts                  # rootProject.name; include(":app")

  gradle/libs.versions.toml            # exact tested dependency versions

  gradlew
  gradlew.bat
  app/
    build.gradle.kts                   # Boot executable, managed BOMs, test suites
    src/main/java/com/example/marketplace/
      MarketplaceApplication.java
      configuration/                  # composition/security/profile wiring, not domain
      shared/                         # MoneyUSD, typed IDs, Actor contracts
      identity/

      ordering/

          package-info.java           # @NamedInterface("api")
```

Identity, Catalog, Inventory, Cart, Promotion and Reviews repeat Ordering's `api/domain/application/adapter` structure only where used. Supporting modules need no empty layers. The Gradle integrationTest suite must explicitly inherit test dependencies, run against PostgreSQL and join `check`; merely creating the folder does not execute it.

```text
dependency direction:
  web adapter -> input API -> application -> domain
  application -> output port <- JDBC adapter
  composition root -> concrete adapters and handlers
prohibited:
  domain -> Spring MVC / JDBC / ORM
  module A -> module B.domain / module B.adapter
  handler -> HTTP request or JDBC Row
```

UC-04 owns a transaction at its application boundary; factories perform construction only. UC-01 queries return projections without aggregate hydration. UC-07 verifies role and portion ownership even when a facade already checked role. Add ArchUnit checks for these directions and Modulith checks for package visibility. Do not split Gradle into one project per aggregate; revisit build modules only when independent compilation provides measurable benefit.

Mapping and generation follow [MapStruct](./3.14-mapstruct.md) and [Lombok](./3.15-lombok.md). Keep mappers in their owning adapters; write constructors explicitly. Before implementing any feature, complete its [test scenario and test-first gate](../4.%20Automated%20Testing/4.%20Automated%20Testing.md).
